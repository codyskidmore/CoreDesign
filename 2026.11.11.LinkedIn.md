CoreDesign 11 is out, built for .NET 11 and C# 15.

CoreDesign is a set of open source NuGet packages for ASP.NET Core APIs: result types instead of exceptions, an EF Core repository layer, generated logging, ProblemDetails error handling and a local identity server. It just passed 10,000 downloads. Thank you.

What's new:

• C# 15 unions replace OneOf. Union<Cabin, NotFoundMessage> works the way OneOf did, and the compiler now warns when a switch misses a case. Existing OneOf code keeps working.

• User journey tracking. Pick a signed-in user and see what they viewed and clicked, in order. Two lines of setup in ASP.NET Core, plus packages for Blazor Server and React (npm: @coredesign.dev/user-journey). An Application Insights workbook is included.

• An AI coding skill. It teaches agents like Claude Code to build with CoreDesign correctly, from a new solution to the first feature.

• Configuration fixes. Environment variables override JSON settings again, and you can choose the settings file name.

• One version for every package. CoreDesign 11 is for .NET 11, and minor releases never break your code.
