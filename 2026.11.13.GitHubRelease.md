## CoreDesign 10.0.1

A patch release for the .NET 10 line. Every CoreDesign package moves to 10.0.1 together. There are no API changes.

### Fixes

- **CoreDesign.Logging: `DecorateWithLogging()` no longer crashes on open generic registrations.** Registering a generic `[LoggingDecorator]` interface as an open generic, such as `AddScoped(typeof(IRepository<>), typeof(Repository<>))`, threw an `ArgumentException` at startup. Open generic registrations are now decorated with the same lifetime. One open generic implementation per interface can be decorated; a second one throws an `InvalidOperationException` that names the interface.
- **CoreDesign.ExceptionHandling: binding failures return 400 instead of 500.** An unmapped `BadHttpRequestException` (a route, query or body value that can't be bound, an oversized body) now keeps its own status code instead of becoming a generic 500. Its message appears in `detail` only in `Development`. A `[ProblemMapping]` for it still takes precedence.

### Requirements

- Both source generators now build against `Microsoft.CodeAnalysis.CSharp` 5.9.0 (from 5.3.0). Your build needs a .NET SDK whose compiler is Roslyn 5.9 or later; SDK 10.0.404 includes it. With an older SDK the compiler reports warning CS9057 and the generators don't run.

### Sample

- The Sample application now references the CoreDesign 10.0.1 packages instead of 1.x, with dependencies updated to match (ASP.NET Core 10.0.15, Aspire 13.6.5, OpenTelemetry 1.21.0, Scalar 2.21.0, `Microsoft.OpenApi` 2.13.0).

### Upgrading from 10.0.0

Change every CoreDesign package reference to `10.0.1` and confirm your SDK with `dotnet --version`. No code changes are needed.
